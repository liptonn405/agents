# Артефакт Архитектора

artifact_id: arch-001

## Цель

Добавить в профиль пользователя статистику по созданным сетям.

## Требования

- Показывать количество сетей, созданных пользователем.
- Показывать дату последней созданной сети.
- Использовать существующий обработчик `user_profile` и не дублировать запросы к БД.

## Критерии готовности

- На странице профиля отображается количество сетей пользователя.
- На странице профиля отображается дата последней созданной сети.
- Запрос к БД выполняется один раз.

## Ограничения

- Сохранить совместимость с Flask, SQLAlchemy и Jinja2.
- Не менять публичные маршруты профиля.

## Затронутые компоненты

- профиль пользователя
- модель Network
- шаблон auth/profile.html

## Вне рамок

- Не добавлять новые страницы.
- Не менять схему авторизации.
