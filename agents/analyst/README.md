# AnalystAgent

**Ответственный:** разработчик №1.

Агент получает описание проблемы (например, GitHub Issue), изучает её и готовит план исправления. Код сюда добавляет ответственный разработчик.

**Планируемые входы:** Issue/текст запроса, путь к доступному репозиторию.

**Планируемые выходы:** структурированное задание для DeveloperAgent и статус готовности.

Контракт обмена данными необходимо согласовать с архитекторами в `shared/contracts/`.

## Условия готовности

- Понятные входные параметры и сообщения об ошибках.
- Невалидные/недостаточные задания не передаются на исправление как готовые.
- Тесты на нормальные и ошибочные сценарии.
- Отсутствие автоматического commit/push.

**Статус:** интерфейс проектируется; реализации пока нет.
