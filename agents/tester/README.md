# TesterAgent

**Ответственный:** разработчик №3.

Агент получает рабочую копию с исправлением, запускает проверки в выделенном окружении и формирует отчёт для оркестратора.

**Планируемые входы:** путь worktree, список изменённых файлов, описание проверок.

**Планируемые выходы:** PASSED / FAILED / BLOCKED и конкретные сообщения об ошибках.

Тестирование непроверенных изменений должно происходить **в изоляции**, без доступа к рабочим БД и секретам.

## Условия готовности

- Воспроизводимый запуск тестов и линтеров.
- Различение падения теста и отсутствия окружения/зависимостей.
- Сбор логов и отчёта для DeveloperAgent.
- Никаких commit/push без явного разрешения.

**Статус:** интерфейс проектируется; реализации пока нет.
