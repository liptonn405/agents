# Orchestrator

**Ответственные:** архитекторы (проектирование), разработчики (интеграция).

Здесь появится логика конвейера:

`Issue → AnalystAgent → DeveloperAgent → TesterAgent → Review`

При ошибках проверок оркестратор может вернуть замечания DeveloperAgent. Он должен ограничивать число попыток и сохранять историю выполнения.

Не смешивайте код оркестратора с файлами конкретных агентов: у каждого своя ответственность.

**Статус:** ещё не реализован.
