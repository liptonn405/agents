# Shared

Общие *согласованные* компоненты для всех агентов: модели данных, форматы ошибок, статусы и утилиты.

**Важно:** каждый агент не должен придумывать отдельный формат передачи задач. Сначала договоритесь о контракте в `contracts/`, затем добавляйте код сериализации/валидации.

Не кладите сюда специфичную логику AnalystAgent, DeveloperAgent или TesterAgent.
